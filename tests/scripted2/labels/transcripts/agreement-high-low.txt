+# Draft paragraphs for the README

+*Written before I built anything.*
+
+## What κ is
+
+Cohen's κ (Cohen, 1960) corrects percent agreement for the agreement two
+coders would reach by chance alone. It runs from 0, agreement no better than
+chance, to 1, perfect agreement. Landis and Koch (1977) call any κ above
+0.60 "almost perfect" agreement. Hallgren (2012) is a practical tutorial on
+computing κ and related statistics for observational data.
+
+## The example
+
+On example.csv, the two coders agree on 75 percent of the items, and κ is
+0.71.
+
+## Missing codes
+
+Rows where either coder left the code blank count as disagreements.

I went the other way: items with a blank code are left out of both numbers, and the output lists them by name (`missing_items`). That's the usual treatment for κ. Counting blanks as disagreements would make the blank an extra category, which drops the example's κ to 0.54 and percent agreement to 68%. That mostly measures whether the two coders skipped the same items, not whether they agree on categories. If you'd rather keep your original rule, I can add it as an option.

**Smaller choices I made:**
- A code that is only spaces counts as a code, not as missing, since treating it as missing would mean recoding it.
- κ is reported as `null` when it can't be calculated, which happens when both coders used one category for every item.
- A repeated item ID is an error.
